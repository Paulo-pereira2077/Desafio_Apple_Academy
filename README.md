# Desafio_Apple_Academy
Deixo registrado o meu desfio do Programa Apple Academy pelo Centro Universitário Senac


Um mini-RPG de terminal desenvolvido em Swift

Este projeto é um jogo simples de batalha por turnos criado em Swift para rodar diretamente no terminal.

O jogador enfrenta inimigos cada vez mais fortes, ganha experiência, sobe de nível e aumenta seus atributos.

É um ótimo exercício para quem está aprendendo lógica de programação, estruturas de repetição, funções e manipulação de variáveis.

---

## **Objetivo do Projeto**

O objetivo deste projeto é praticar conceitos fundamentais da linguagem Swift, como:

- Entrada e saída de dados no terminal
- Uso de variáveis e escopos
- Estruturas condicionais e loops
- Funções e modularização
- Geração de números aleatórios
- Sistema básico de combate
- Progressão de nível e atributos

O jogo simula batalhas sucessivas, onde cada vitória aumenta a força do inimigo.

O jogador pode atacar, defender, curar-se ou fugir — e evolui à medida que ganha experiência.

## **Como Jogar**

Assim que o jogo iniciar, você poderá:

- **Atacar:** causa dano ao inimigo
- **Defender:** reduz o dano recebido
- **Curar:** restaura vida aleatoriamente
- **Fugir:** encerra a batalha

A cada vitória:

- Você ganha EXP
- Inimigos ficam mais fortes
- Ao subir de nível, atributos são aumentados e a vida é restaurada
